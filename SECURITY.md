# Security Policy

## Reporting

Do not open a public issue containing API keys, Tunnel IDs, account identifiers, private logs, personal data, or REA sample files. For sensitive reports, use a private communication channel with the repository maintainer.

## Supported scope

This repository contains deployment documentation and local management scripts. It is not an OpenAI-operated product and does not grant access to OpenAI services by itself.

## Credential handling

Never commit Runtime API Keys, OAuth tokens, Authorization headers, cookies, real tunnel profiles, or unredacted logs. Revoke or rotate any credential that may have been exposed.
